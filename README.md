# Undotted Sulfur Cubes
[This Resource Pack](https://modrinth.com/resourcepack/undotted-sulfur-cubes) removes the dots from Sulfur Cubes, aiming to help you better see the blocks they absorb.

# Installation instructions
If you haven't already, download the latest version of the resource pack via [Modrinth](https://modrinth.com/resourcepack/undotted-sulfur-cubes/versions).

Open up Minecraft Java Edition on the device where you downloaded the resource pack. Once loaded, press "Options…" then press "Resource Packs…". You should see a page showing you all the resource packs you've installed. Press "Open Pack Folder" to open up your file explorer, then open up a second window in your file explorer and navigate to where you downloaded the resource pack. Drag that resource pack into the first window, then return to Minecraft. Somewhere in the "Available" resource packs list, you'll find Undotted Sulfur Cubes. Press the right arrow above its icon, then press "Done".

# How did I create it?
I simply extracted the textures from [Minecraft](https://www.minecraft.net/)'s 26.2 JAR and edited the textures via [Pixelorama](https://pixelorama.org/).
To maintain accuracy with colors, I used the eyedropper tool and erased pixels before overwriting them.
