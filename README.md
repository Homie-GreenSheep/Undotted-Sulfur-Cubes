# Undotted Sulfur Cubes
[This Resource Pack](https://modrinth.com/resourcepack/undotted-sulfur-cubes) removes the dots from Sulfur Cubes, aiming to help you better see the blocks they absorb.

# Installation instructions
If you haven't already, download the latest version of the resource pack via [Modrinth](https://modrinth.com/resourcepack/undotted-sulfur-cubes/versions).
Open up Minecraft Java Edition on the device you downloaded the resource pack on. Once loaded, press "Options…" then press "Resource Packs…". It should show you a page showing you all resource packs you've installed. Press "Open Pack Folder" to open up your file explorer, and open up a second window in your file explorer to where you downloaded that resource pack to. Drag that resource pack into the first window opened, then return to Minecraft, where somewhere in the "Available" resource packs list, you'll find Undotted Sulfur Cubes. Press the right arrow above its icon then press "Done".

# How did I create it?
I simply extracted the textures from [Minecraft](https://www.minecraft.net/)'s 26.2 JAR and edited the textures via [Pixelorama](https://pixelorama.org/).
To maintain accuracy with colors, I used the eyedropper tool and erased pixels before overwriting them.
