# Undotted Sulfur Cubes
[This Resource Pack](https://modrinth.com/resourcepack/undotted-sulfur-cubes) removes the dots from Sulfur Cubes, aiming to help you better see the blocks they absorb.

# How did I create it?
I simply extracted the textures from [Minecraft](https://www.minecraft.net/)'s 26.2 JAR and edited the textures via [Pixelorama](https://pixelorama.org/).
To maintain accuracy with colors, I used the eyedropper tool and erased pixels before overwriting them.
